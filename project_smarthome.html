ESP32 스마트홈

웹 통신 기반 사물인터넷 센서 연동 자동화 하우스 프로젝트입니다. 회로 설계, 납땜과 하드웨어 제작을 담당했습니다.

2023 전교생 해커톤 우수상ESP32센서·모터 제어웹 서버

프로젝트 목적

ESP32가 생성한 무선 네트워크와 웹 서버에 접속하여 스마트폰이나 컴퓨터에서 집 안의 장치를 원격으로 제어하는 시스템을 구현했습니다.

주요 기능

실시간 온도 확인

DS18B20 온도센서 값을 읽어 웹 화면에 표시합니다.

조명 제어

네오픽셀 색상과 메인 조명의 밝기를 웹에서 제어합니다.

자동 블라인드

조도센서 값에 따라 서보모터로 블라인드를 자동 개폐합니다.

보안문 제어

적외선 센서와 부저를 연동해 움직임을 감지하고 문을 제어합니다.

통신 구조

클라이언트에서 HTTP 요청을 보내면 ESP32 웹 서버의 경로별 처리 함수가 실행되고, 해당 함수가 센서 또는 구동부를 제어하도록 구성했습니다.

// 예시 구조
웹 버튼 클릭
  → HTTP GET 요청
  → ESP32 경로 처리 함수
  → 네오픽셀·서보모터·부저 제어
  → 상태 응답

담당 역할

  • 센서와 구동부 연결을 위한 회로 설계
  • 납땜, 배선 및 작품 하드웨어 제작
  • 웹 기반 장치 제어 기능 구현과 시험
