# 백주원 이력서 사이트

정적 HTML/CSS/JavaScript로 만든 간단한 개인 이력서 사이트입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다.

## 구조

- `index.html` : 메인 페이지
- `style.css` : 반응형 디자인
- `script.js` : 모바일 메뉴, 연도 표시
- `assets/profile-casual.png` : 메인 프로필 사진
- `assets/profile-formal.png` : 이력 섹션 증명사진
- `assets/baek-juwon-resume.pdf` : 이력서 PDF

## 배포

GitHub Pages, Netlify, Cloudflare Pages 등 정적 호스팅에 그대로 올릴 수 있습니다.
