시큐어지피티

C 언어 코드를 입력하면 생성형 인공지능이 취약점을 분석하고 안전한 코드 작성 방향을 제시하는 교육용 웹 서비스입니다.

2024 영남권 연합 해커톤 인기상PythonFlask생성형 인공지능 연동

기획 배경

초보 학습자는 버퍼 오버플로, 입력값 검증 누락과 같은 C 언어 보안 문제를 코드만 보고 파악하기 어렵습니다. 코드 입력, 취약점 설명, 개선 코드 제안을 한 화면에서 확인할 수 있도록 구성했습니다.

서비스 흐름

1. 코드 입력

학습자가 검사할 C 언어 코드를 웹 화면에 입력합니다.

2. 서버 전달

플라스크 서버가 입력 내용을 분석 요청 형식으로 정리합니다.

3. 취약점 분석

생성형 인공지능 응용 프로그램 인터페이스로 취약점과 원인을 분석합니다.

4. 학습 결과

취약점 설명, 개선 코드와 안전한 작성 방법을 함께 보여줍니다.

교육 기능

  • 정수형 오버플로와 메모리 버퍼 오버플로 개념 안내
  • 취약한 코드와 개선된 코드를 비교하는 검사 화면
  • 보안 개념을 확인하는 간단한 퀴즈 구성

담당 역할

  • 팀장으로 주제와 서비스 흐름 기획
  • 플라스크 기반 웹 화면과 서버 기능 구현
  • 생성형 인공지능 분석 기능 연동과 결과 화면 구성
